## INVENTORY LOOK MECHANIC

```
ESTABLISHED IN THIS SCENE — APPLIES THROUGHOUT ENTIRE GAME.

Every item in the player's inventory can be EXAMINED.

HOW IT WORKS:
- Player opens inventory (I key)
- Selects any item
- Presses LOOK (or clicks EXAMINE)
- A small panel appears:
  1. VISUAL DESCRIPTION (what it looks like)
  2. HER THOUGHT (inner monologue response)
  3. OCTOPUS REACTION (color shift, physical response — always present)
  4. MEMORY FRAGMENT (appears only sometimes, only with significant items)

Items do not always give the same response.
Some items reveal MORE as the story progresses (she processes them differently).
Some items change meaning after certain discoveries.
```
